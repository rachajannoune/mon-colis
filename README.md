# Mon Colis La Poste

Mini-application Nuxt 3 réalisée dans le cadre d’un exercice d’évaluation technique.

## Objectif

L’application aura pour fonctionnalités :

- le suivi de colis ;
- la recherche de bureaux de poste ;
- la simulation de tarifs d’envoi ;
- un espace utilisateur connecté simulé.

## Stack actuelle

- Nuxt 3
- Vue 3
- TypeScript
- Nitro
- ESLint

Le projet utilise Node.js 24.21.0.
